# NFL Play-by-Play Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of NFL (National Football League) play-by-play data. The goal is to explore football game data, identify patterns, analyze player and team performance, and visualize important statistics.

## Objectives
- Understand the structure of the NFL play-by-play dataset.
- Clean and preprocess the data.
- Analyze missing values and duplicate records.
- Explore passing, rushing, penalties, and other play-related statistics.
- Create visualizations to identify trends and patterns.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Requirements
Install the required libraries using:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

## Dataset
The project uses NFL play-by-play data. The dataset contains information about football plays, game situations, teams, and play outcomes.

Place the dataset CSV file in the project folder before running the notebook.

## How to Run
1. Download or place the dataset in the project directory.
2. Open the Jupyter Notebook.
3. Install the required Python libraries.
4. Run the notebook cells in order.
5. Review the analysis results and visualizations.

## Analysis Performed
- Data inspection and cleaning
- Missing-value analysis
- Duplicate detection
- Descriptive statistics
- Team and play analysis
- Data visualization

## Expected Outcomes
The analysis helps identify patterns in NFL play-by-play data and provides insights into game situations, play outcomes, and team performance.
